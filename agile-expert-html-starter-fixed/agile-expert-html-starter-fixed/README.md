# Agile Expert — Proyecto HTML Base

Estructura mínima con **buenas prácticas**:
- Fondo blanco/gris y **acentos de color** (variables CSS).
- HTML semántico, accesible (skip-link, focus visible).
- **CSS separado** (sin estilos inline), convenciones BEM.
- Componentes reutilizables: botones, tarjetas, alertas, badges, tabla, formulario.

## Estructura
```
index.html
asset/
  css/
    estilos.css
  doc/
  img/
```

## Uso
Abre `index.html` en tu navegador. Ajusta acentos modificando las variables CSS en `asset/css/estilos.css`.
